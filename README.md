# AudioBox 🎧

**A modern Android music player built with Kotlin and Jetpack Compose.**

AudioBox is an Android music player project focused on a clean, modern listening experience, with a user interface inspired by Apple Music.

> **Current version:** v1.0.0  
> **Status:** Initial release

## ✨ Features

- 🎵 Music player interface built with Jetpack Compose.
- 🎨 Modern UI inspired by Apple Music.
- 📱 Native Android application.
- 📦 Signed APK available for installation.

*Feature availability may vary as development continues.*

## 🛠️ Tech Stack

- **Language:** Kotlin
- **UI Framework:** Jetpack Compose
- **Platform:** Android
- **IDE:** Android Studio

## 📥 Installation

1. Open the [Releases](https://github.com/stealh38-sukakkau/AudioBoX/releases) page.
2. Download the latest `app-release.apk`.
3. Open the downloaded APK on your Android device.
4. Follow Android's installation prompts.
5. Launch AudioBox.

If Android asks for permission to install apps from your browser or file manager, allow it only for the app you are using to install AudioBox.

## ⚠️ Known Issues

- The Now Playing interface may return to the initial track after navigating between tracks and reopening the app.

These issues may be addressed in future updates.

## 🚀 Development

To explore or build AudioBox locally:

1. Clone this repository:

   ```bash
   git clone https://github.com/stealh38-sukakkau/AudioBoX.git
   ```

2. Open the project in Android Studio.
3. Allow Gradle to sync.
4. Connect an Android device or configure an emulator.
5. Build and run the application.

Build requirements may depend on the project's current Gradle and Android SDK configuration.
